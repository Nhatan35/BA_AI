# Regulation Register Guide

Với mỗi regulation/standard, lưu:
- Regulation ID
- Name
- Version/Number
- Jurisdiction
- Effective date
- Applicable scope
- Official source
- Last reviewed
- Status: Active / Superseded / Repealed / Review Needed

## AI rule
AI chỉ **flag potential regulatory impact + trích nguồn**; không tự đưa ra kết luận pháp lý cuối cùng.
