# Prompt — Impact Analysis

Dựa trên Change Request và Requirement Graph được cung cấp, xác định:
- Requirements affected
- Business Rules
- Process
- UI
- Data
- Permissions
- API/Integration
- NFR
- Risks/Clinical Safety
- User Stories/AC
- Test/UAT
- Documents
- External systems

Không tự approve change. Nếu traceability thiếu, nêu rõ node/link còn thiếu thay vì đoán.
