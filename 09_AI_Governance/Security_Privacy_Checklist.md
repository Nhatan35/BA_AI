# Security & Health Data Privacy Checklist

- [ ] Project/workspace isolation.
- [ ] Role-based access.
- [ ] Sensitive health/personal data identified.
- [ ] Minimum necessary data principle considered.
- [ ] No secrets/API keys stored in prompts/docs unnecessarily.
- [ ] Source permissions respected.
- [ ] Prompt injection/untrusted content handling.
- [ ] Output checked for sensitive information leakage.
- [ ] Audit for AI actions where required.
- [ ] Retention/deletion policy defined.
- [ ] Export/sharing permissions defined.
- [ ] Legal/compliance review for applicable requirements.
