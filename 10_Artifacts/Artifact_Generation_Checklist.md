# Artifact Generation Checklist

Trước khi AI tạo tài liệu chính thức:
- [ ] Đúng Project ID.
- [ ] Chỉ dùng Source of Truth hiện hành.
- [ ] Requirement status phù hợp với loại tài liệu.
- [ ] Không dùng Decision đã superseded.
- [ ] Không dùng Assumption như fact.
- [ ] Conflict đã được resolve hoặc nêu rõ.
- [ ] Traceability còn nguyên.
- [ ] Version + date + owner được ghi.

## Artifacts có thể tạo
- BRD / FRD / SRS
- Requirement List
- User Stories + AC
- As-Is / To-Be
- Business Rules
- Data Dictionary
- Role-Permission Matrix
- API Inventory / Mapping
- Risk Register
- Decision Log
- Question Log
- RTM
- UAT Pack
- Change Request / Impact Analysis
- Meeting Minutes
